# Suggested Commands

## Development

- `npm start`: Dev mode with `templates/baseConfig.js`
- `npm run dev`: Alias for start
- `npm run dev:lib`: Dev mode for library development

## Building

- `npm run build`: Build application
- `npm run build:lib`: Build library only (dist/client)
- `npm run build:cli`: Build CLI (rolldown)
- `npm run build:types`: Generate declarations

## Quality Control

- `npm run check`: Type check and lint
- `npm run lint`: Lint and fix
- `npm run format`: Prettier format
- `npm test`: Run all tests (Vitest)
- `npm run test:unit`: Unit tests
- `npm run test:browser`: Browser tests (Playwright)

## Documentation

- `npm run docs:dev`: Run documentation dev server (port 3333)
- `npm run docs:build`: Build documentation
