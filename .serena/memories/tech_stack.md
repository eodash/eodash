# Tech Stack

## Languages & Runtimes

- TypeScript / JavaScript (ESM)
- Node.js >= 24.0.0

## Frameworks & Libraries

- **Frontend**: Vue 3, Vuetify 3, Pinia
- **EOx Integration**: Heavy use of EOxElements (`@eox/*`)
- **Maps**: OpenLayers (via `@eox/map`)
- **Styles**: SASS

## Build & Tooling

- **Bundler**: Rolldown (CLI), Vite (Client)
- **CLI**: Commander.js
- **Type Checking**: vue-tsc
- **Documentation**: VitePress, TypeDoc
- **Linting/Formatting**: ESLint, Prettier
