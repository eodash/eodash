# How to Export EODash Documentation as PDF

## Prerequisites
1. Ensure dependencies installed:
   npm install

2. Ensure `vitepress-pdf.config.mjs` exists in repository root with Linux Puppeteer sandbox flags and route exclusions:
   ```javascript
   /**
    * @type {import('vitepress-export-pdf').UserConfig}
    */
   export default {
     routePatterns: [
       "/**",
       "!/404.html",
       "!/404",
       "!/cookie-settings",
       "!/cookie-settings.html",
     ],
     puppeteerLaunchOptions: {
       args: [
         "--no-sandbox",
         "--disable-setuid-sandbox",
         "--disable-dev-shm-usage",
         "--disable-gpu",
       ],
     },
   };
   ```

## Steps to Export PDF

1. (Optional) Generate API documentation if not already present:
   npm run docs:generate

2. Export docs to PDF:
   npm run export-pdf

   Or run directly with custom output name:
   npx press-export-pdf export docs --outFile eodash-client-docs-snapshot-$(date +%Y%m%d).pdf --debug

3. The generated PDF will be created in repository root directory.
